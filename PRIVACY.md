# CallTone Mac Privacy Policy

CallTone Mac processes call signals and audio on your Mac. It does not send call information, audio, your ringtone library, or your settings to the developer. It has no account, advertising, analytics, or tracking SDK.

With macOS Accessibility permission, CallTone Mac inspects Apple call controls to detect ringing. With macOS System Audio Recording permission, it can mute the audio of selected calling processes while a replacement ringtone plays. It does not save audio from those taps. Imported ringtones and settings stay in the app’s local library. Uninstalling the app does not delete that library.

The GitHub edition contacts GitHub if you check for updates or enable optional automatic update checks. The request retrieves public release information and contains no call data, ringtone data, account credentials, or app settings. GitHub receives normal connection information, including your IP address, under its own privacy policy. Choosing to open a release or this privacy policy also opens GitHub in your browser.

You can disable automatic checks and revoke Accessibility or System Audio Recording permissions in macOS System Settings. For questions, use the GitHub repository’s Issues page without posting personal call or audio data.
